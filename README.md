# 📊 학생 생활 습관 및 학교생활 만족도 대시보드

학생회 데이터 담당자가 설문조사 CSV 파일을 업로드하여 학과별 생활 습관, 수면 시간, 스마트폰 사용 시간과 학교생활 만족도의 관계를 직관적으로 분석하고 확인할 수 있는 웹앱입니다.

## ✨ 주요 기능
- **CSV 파일 업로드 및 실시간 미리보기**
- **자동 데이터 전처리**: 결측치 및 '모름' 응답 자동 정제 및 제외 건수 통계 제공
- **학과별 필터링**: 특정 학과 선택 시 평균 만족도 및 지표 동적 연동
- **인터랙티브 시각화 (Plotly)**:
  - 생활습관(공부·수면·스마트폰)과 만족도의 상관관계 산점도
  - 학생 한 줄 의견 주요 키워드 빈도 분석 막대그래프
